# TestBot curated governance and architecture docs

This site provides the curated, human-authored governance and architecture authority pages,
plus API documentation generated from validator/gate source modules.

## Authority model

- Canonical governance ownership remains the curated map in `docs/governance/governance-authority-map.md`.
- Generated API pages are descriptive implementation references, not normative authority declarations.
